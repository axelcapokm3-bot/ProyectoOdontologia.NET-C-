 🦷 Sistema Web de Gestión Odontológica

Plataforma web integral diseñada para la administración eficiente de clínicas odontológicas, optimizando la gestión de turnos, pacientes, odontólogos y tratamientos mediante una arquitectura limpia y desacoplada.

 🚀 Características Principales

* **Gestión de Agenda y Turnos:** Registro, actualización y cancelación de turnos con validación automática de solapamientos de horarios.
* **Algoritmo de Detección de Huecos:** Cálculo automático de intervalos de tiempo disponibles entre turnos según la duración requerida.
* **Control de Pacientes y Odontólogos:** Historia clínica, datos de contacto y asignación de tratamientos.
* **Arquitectura Robusta:** Implementación basada en principios de Onion Architecture / Domain-Driven Design (DDD) con separación en capas (Aplicación, Dominio, Infraestructura).

🛠️ Tecnologías Utilizadas

* **Lenguaje:** C# (.NET)
* **Arquitectura:** Layered / Onion Architecture
* **Patrones:** Repository Pattern, DTOs, Value Objects
* **Persistencia:** Entity Framework Core / SQL Server
